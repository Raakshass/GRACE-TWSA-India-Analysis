# Data Directory

This directory should contain the following data files before running the analysis scripts.

## Required Data Files

### 1. GRACE/GRACE-FO CSR RL06.3 Mascon Data
- **File**: `CSR_GRACE_GRACE-FO_RL0603_Mascons_all-corrections.nc`
- **Size**: ~113 MB
- **Download**: https://www2.csr.utexas.edu/grace/RL0603_mascons.html
- **Description**: Monthly mascon solutions (0.5° × 0.5°) with all corrections applied, April 2002 – present

### 2. India Boundary GeoJSON
- **File**: `india_boundary.geojson`
- **Source**: https://github.com/datameet/maps
- **Description**: Official India composite boundary (including J&K, Ladakh) in GeoJSON format

### 3. TWSA Reconstruction Dataset (for gap-filling)
- **File**: `TWSA_Reconstruction_Locally_Adaptive_Ensemble_1980-2024_v1.xlsx`
- **Size**: ~430 MB
- **Download**: https://doi.org/10.5281/zenodo.15107065
- **Description**: Monthly reconstructed TWSA at 1° resolution, used to fill the 11-month GRACE/GRACE-FO gap (July 2017 – May 2018)

### 4. IMD Gridded Daily Rainfall
- **Downloaded automatically** by `02_imd_precipitation/download_imd.py`
- **Source**: https://www.imdpune.gov.in/cmpg/Griddata/Rainfall_25_Bin.html
- **Resolution**: 0.25° × 0.25°, daily

### 5. ESA WorldCover Tiles
- **Downloaded automatically** by `05_lulc_analysis/extract_lulc.py`
- **Source**: https://esa-worldcover.org/en
- **Resolution**: 10 m

## Hotspot ROI Boundaries
- **File**: `all_hotspots.geojson` — generated by `03_hotspot_identification/hotspot_extraction.py`
- Contains 4 ROI polygons (ROI1–ROI4) with attributes: roi_id, type, threshold, center_trend
